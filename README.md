# Retro OS v1
a classic windows 95 lookalike desktop os simulation
made by **gebe** for hack club :3

---
## features
* **windows that can drag:** u can open, close, drag, & stack multiple app windows
* **start menu & taskbar:** classic taskbar with a start menu & real time clock
* **bunches of apps!:** there are notepad, file explorer, paint, terminal, calculator, snake game, and settings
* **mobile support (yes, it works on mobile!!!):** we can use this os simulation on mobile, but don't expect max performance pls

## how to run
1. go to ur browser
2. open [https://retro-os-2pu.pages.dev/](https://retro-os-2pu.pages.dev/) to da address bar
